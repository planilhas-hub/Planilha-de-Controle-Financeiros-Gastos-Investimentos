⚙️ Guia de Configuração — Mercado Pago + Envio Automático de E-mail

Siga os passos abaixo para colocar tudo funcionando automaticamente. Não precisa programar.

1

Crie sua conta de vendedor no Mercado Pago

Acesse mercadopago.com.br → crie uma conta como pessoa física ou jurídica → complete a verificação de identidade. Isso leva cerca de 10 minutos.

💡 Use o mesmo CPF/CNPJ que você usará para receber os pagamentos. O dinheiro cai direto na conta do Mercado Pago e você transfere quando quiser.
2

Crie o Link de Pagamento (sem precisar programar)

No painel do Mercado Pago: Cobranças → Link de pagamento → Criar link. Configure assim:

// Configure desta forma no formulário do Mercado Pago: Nome do produto: "Planilha de Controle de Gastos e Investimento" Preço: R$ 9,90 Descrição: "Dashboard + Investimentos + Metas - 8 abas" Tipo: Produto digital (único pagamento) URL de retorno: https://SEU-SITE.github.io/obrigado.html

Copie o link gerado e substitua no botão href="..." deste arquivo checkout.html.

3

Configure o envio automático do arquivo por e-mail (via Zapier — grátis)

O Zapier conecta o Mercado Pago ao Gmail/Outlook e envia o e-mail com o arquivo automaticamente após cada venda confirmada:

🛒
Mercado Pago
Novo pagamento aprovado
→
⚡
Zapier
Automatiza a ação
→
📧
Gmail
Envia o arquivo
// Como configurar no Zapier (zapier.com — gratuito até 100 tarefas/mês): 1. Crie uma conta em zapier.com 2. Clique em "Create Zap" 3. TRIGGER: escolha "Mercado Pago" → evento "New Payment" → conecte sua conta MP → filtre por status = "approved" 4. ACTION: escolha "Gmail" → ação "Send Email" → configure o e-mail assim: Para: {{payment.payer.email}} (e-mail do comprador) Assunto: "✅ Sua Planilha Chegou! Acesse Agora" Corpo: "Olá {{payment.payer.name}}! Seu pagamento foi confirmado. Baixe sua planilha aqui: [LINK DO GOOGLE DRIVE]" 5. Teste e ative o Zap ✓
💡 Onde hospedar o arquivo: Suba o arquivo .xlsx no Google Drive → clique com o botão direito → "Compartilhar" → "Qualquer pessoa com o link". Copie o link e coloque no e-mail acima.
4

Publique o site no GitHub Pages (gratuito)

O GitHub Pages hospeda seu site de forma gratuita com URL no formato https://SEU-USUARIO.github.io/SEU-REPOSITORIO:

// Passo a passo para publicar no GitHub Pages: 1. Crie uma conta em github.com 2. Clique em "New Repository" → nomeie como finanControl 3. Faça upload dos arquivos: → index.html → checkout.html → obrigado.html (página pós-compra) 4. Vá em Settings → Pages 5. Em "Source", selecione main branch → / (root) 6. Clique "Save" — em ~2 minutos seu site estará no ar! // URL final: https://SEU-USUARIO.github.io/finanControl
💡 Domínio personalizado (opcional): Se quiser usar seu próprio domínio (ex: planilhafinanceiro.com.br), compre no registro.br (~R$40/ano) e configure em Settings → Pages → Custom Domain.
5

Crie a página de "Obrigado" (pós-compra)

O Mercado Pago redireciona o comprador para uma URL após o pagamento. Crie um arquivo obrigado.html com a mensagem de confirmação e reforce que o arquivo chegará por e-mail em até 5 minutos.

✅ Fluxo completo funcionando: Cliente compra → Mercado Pago processa → Zapier detecta pagamento aprovado → Gmail envia e-mail com o link do arquivo automaticamente. Tudo sem você precisar fazer nada manualmente!
