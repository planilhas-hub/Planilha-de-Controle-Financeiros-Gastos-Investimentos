🏦 Planilha de Controle de Gastos e Investimento — Site de Vendas
Landing page de alta conversão para venda de planilha financeira em Excel (.xlsx). O site inclui simulações interativas das abas da planilha (Dashboard, Despesas, Investimentos e Metas), seção de benefícios, depoimentos, FAQ com accordion e página de checkout integrada ao Mercado Pago com guia de automação de envio por e-mail via Zapier.
Arquivos:

index.html — Página principal de vendas
checkout.html — Página de checkout com Mercado Pago + guia de configuração
obrigado.html — Página de confirmação pós-compra
